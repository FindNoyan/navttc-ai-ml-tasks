# NAVTTC AI/ML (Machine Learning & Deep Learning) — Solved Tasks

Solutions to Tasks 1–27 from the NAVTTC "Artificial Intelligence
(Machine Learning & Deep Learning)" course, Prime Minister's
Hunarmand Pakistan Program.

Each folder is one task, matching the numbering in the course's
Annexure-I task list. Tasks 1 and 2 are notes (installation, Linux
commands); Tasks 3–27 are Python exercises.

## Structure

```
task-01-installation/          notes on tools installed
task-02-linux-commands/        notes on Linux commands practiced
task-03-add-two-numbers-.../   solution.py
...
task-27-user-defined-.../      solution.py
```

- **Body:** National Vocational and Technical Training Commission (NAVTTC)
